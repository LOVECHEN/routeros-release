## English

Official **MikroTik RouterOS v6 / v7** downloads and historical archive, including architecture-specific packages, CHR images, installation images and companion tools such as Netinstall.

Use **[Search Downloads](https://lovechen.github.io/routeros-release/)** to select an exact version (grouped by v7 / v6) and filter by filename, channel and architecture, newest first. Browse **[GitHub Releases](https://github.com/LOVECHEN/routeros-release/releases)** or download **[Latest Stable](https://github.com/LOVECHEN/routeros-release/releases/latest)**.

Files with the same version are grouped together with their original filenames. Each release includes a SHA-256 table and `checksums.sha256`.

All files are unmodified. Copyright belongs to MikroTik.

Historical final releases are retained. Only the current testing/development previews are kept; obsolete beta/rc releases are not backfilled.
