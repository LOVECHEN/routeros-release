# RouterOS 官方下载与历史版本

[中文](#中文) | [English](#english)

## 中文

MikroTik **RouterOS v6 / v7** 官方原版下载镜像与历史版本归档，包含各架构软件包、CHR 虚拟机镜像、安装镜像和 Netinstall 等配套工具。

打开 **[GitHub Releases](https://github.com/LOVECHEN/routeros-release/releases)** 按版本下载，或直接获取 **[最新稳定版](https://github.com/LOVECHEN/routeros-release/releases/latest)**。

同版本文件合并归档，保留原始文件名。每个 Release 的表格提供 SHA-256，附件中包含 `checksums.sha256`。

所有文件未经修改，软件版权归 MikroTik。

## English

Official **MikroTik RouterOS v6 / v7** downloads and historical archive, including architecture-specific packages, CHR images, installation images and companion tools such as Netinstall.

Browse **[GitHub Releases](https://github.com/LOVECHEN/routeros-release/releases)** by version, or download **[Latest Stable](https://github.com/LOVECHEN/routeros-release/releases/latest)**.

Files with the same version are grouped together with their original filenames. Each release includes a SHA-256 table and `checksums.sha256`.

All files are unmodified. Copyright belongs to MikroTik.
