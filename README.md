MikroTik **RouterOS v6 / v7** 官方原版下载镜像与历史版本归档，包含各架构软件包、CHR 虚拟机镜像、安装镜像和 Netinstall 等配套工具。

在 Releases 搜索框输入版本号查找历史版本。同版本文件按 Architecture 分组，点击文件名直接下载；表格提供 SHA-256，附件中包含 `checksums.sha256`。

现有正式版归档持续保留，今后自动追踪各渠道新版本；beta / rc 仅保留当前最新、且尚未被同一大版本正式版取代的测试版。

检测到 stable / longTerm 正式版本后，自动清理已被取代的 beta / rc Release 及其附件；更高版本的测试版不受影响，正式版归档不删除。

所有文件未经修改，软件版权归 MikroTik。

## English

Official **MikroTik RouterOS v6 / v7** downloads and historical archive, including architecture-specific packages, CHR images, installation images and companion tools such as Netinstall.

Browse **[GitHub Releases](https://github.com/LOVECHEN/routeros-release/releases)** and search by version, or download **[Latest Stable](https://github.com/LOVECHEN/routeros-release/releases/latest)**.

Files with the same version are grouped together with their original filenames. Each release includes a SHA-256 table and `checksums.sha256`.

All files are unmodified. Copyright belongs to MikroTik.

Existing final releases are retained while new channel versions are tracked automatically. Only current testing/development previews not superseded by an equal or newer final release within the same major version are kept.

Stable / longTerm releases automatically retire superseded beta / rc releases and their assets. Newer preview targets and final release archives are preserved.
